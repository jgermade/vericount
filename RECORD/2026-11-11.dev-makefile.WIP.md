## 2026-11-11: make up, make test, make build

Author's instructions: a Makefile where `make test` runs the project's tests, `make up` runs the application locally in development mode and `make build` builds it.

- `docker-compose.dev.yml` (project `vericount-dev`): PostgreSQL 16 on `127.0.0.1:5433` (so it does not collide with a local PostgreSQL) and Mailpit on 1025/8025. The owner `vericount_owner` is the image's superuser, so it also creates the tests' temporary databases; `docker/initdb` creates the server's role `vericount`. Fixed passwords: development only.
- `make up`: services, `migrate` with `VERICOUNT_APP_ROLE=vericount`, then `scripts/dev.sh`, which runs the AEAT mock (port 8090, with schema validation), the server (8080) and Vite (5173) and stops all three when one exits or on Ctrl+C. `VERICOUNT_PUBLIC_URL` is Vite's address, since the client is opened there and passkeys are bound to it. Sending is on, to the mock, with a placeholder producer.
- `make test`: builds the client and runs `cargo test --workspace` with the same variables as CI (`DATABASE_URL`, `VERICOUNT_TEST_SMTP_URL`, `VERICOUNT_TEST_MAILPIT_URL`). `make lint` holds the other CI checks; shellcheck and helm are skipped when not installed.
- `make build`: client and release server for the host. The static musl binaries and the image remain CI's (`build.yml`, `docker build`).
- Also `make invite EMAIL=...`, `check`, `down`, `reset` (deletes the volume) and `clean`.

Bug found while trying `make up`: `npm run dev` never worked for anything but GETs. Vite's string shorthand for a proxy sets `changeOrigin: true`, so the server received `Host: 127.0.0.1:8080` with `Origin: http://localhost:5173` and refused every POST as CSRF. `vite.config.ts` now keeps the Host header. It also turns off Vite's dependency scan, which fails on the `.html` components and has nothing to pre-bundle.

Vite is started directly, not through `npm run dev`: npm does not pass SIGTERM on, and Vite outlived the script.

Checked: `make test` passes (69 tests). With `make up`, `make invite` and the browser, the invitation, the code email in Mailpit and the sign-up work; the server logs that it sends records to the mock.

Open: the author says the AEAT sync stays in test mode (against the mock) until a certificate is assigned, and then live mode can be turned on. Asked how that should work before building it.
